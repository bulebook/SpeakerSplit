# SpeakerSplit 使用说明

本地把视频/音频里不同人的说话声分开、转成文字，检查修正后按人导出 WAV。
所有处理都在本机完成，不上传素材、声纹或转写结果。

---

## 一、安装（只做一次）

1. 需要 Windows 10/11 和 Python 3.11。
2. 在项目目录里右键 `install.ps1` → 选择"使用 PowerShell 运行"。
3. 脚本会自动做三件事：
   - 创建 `.venv` 虚拟环境
   - 下载 CUDA 版 PyTorch（约 2.6 G）并安装
   - 安装其余依赖

> 如果 PowerShell 拦截脚本，先在终端执行：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

## 二、启动

双击 **`run_ui.bat`**。

## 三、第一次处理

第一次点"开始处理"时会自动下载三个模型：

| 用途 | 模型 | 大小 |
|---|---|---|
| 语音转文字 | faster-whisper large-v3-turbo | 约 1.6 G |
| 去背景音乐 | Demucs htdemucs | 约 80 M |
| 说话人识别 | pyannote 分割 + 3D-Speaker 声纹 | 约 35 M |

国内网络会自动走镜像（HuggingFace → hf-mirror，GitHub → 可配代理）。
模型下齐之后，断网也能正常使用。

## 四、界面怎么看

- **左侧栏**：顶部是「导入视频或音频」按钮；下面是处理步骤（当前步骤蓝色高亮，走过的打勾，并显示各阶段耗时）
- **标题中间**：「检查 / 编辑」切换，处理完成后可以进入音频编辑器
- **标题旁状态胶囊**：已导入 / 处理中 / 待检查 / 已导出
- **右上角主按钮**：随进度自动变化——选择文件 → 开始处理 → 导出
- **左侧栏下方**：识别出的说话人（头像是序号，后面是句数和总时长）
- **中间上方**：波形时间轴，彩色细条表示谁在说话，点任意位置跳转
- **中间下方**：片段表格，每行是一句话及它的说话人
- **底部**：播放 / 暂停（空格键）、播放进度、音量

## 五、完整流程

1. **导入**：把视频或音频拖进窗口，或点左侧「导入视频或音频」。
   有多条音轨的视频，在 设置 › 人声分离 的「处理方式」里选择要用的音轨。
2. **清理**：在 设置 › 人声分离 的「处理方式」里选「去人声」或「保留原声」。
   同一页可以换人声分离模型，列表里标了效果分、文件大小、速度和显存占用；
   未下载的模型点"下载"会自动下载到程序目录。
   默认是 **MelBand RoFormer（Kim）**：效果分最高（12.60），实测也最快。

   识别模型在 设置 › 文字识别，可选**标准**（large-v3-turbo，快）或**高精度**（large-v3，方言和错字更准，首次需下载约 3G）。
   声纹模型在 设置 › 声纹识别，默认 **3D-Speaker CAM++ 中文**（约 27 MB），可换成中英混合、ERes2NetV2、WeSpeaker 等；未下载的会在处理时自动下载。
3. **开始处理**：点主按钮，等待进度走完。
   有 NVIDIA 显卡会自动用 GPU，没有则用 CPU。
4. **检查修正**：见下一节。
5. **导出**：点主按钮"导出"，选择文件夹。

## 六、检查修正怎么操作

| 想做的事 | 操作 |
|---|---|
| 试听某一句 | 单击这一行：波形放大到该句，**只播这一句，播完自动停** |
| 播放 / 暂停 | 按 **空格键**，或点左下角播放按钮 |
| 恢复全景波形 | 点时间轴右上角"显示全部"，或双击时间轴 |
| 看哪里有多人重叠 | "状态"列显示"重叠"的片段，建议人工确认 |
| 改文字 | 双击"文字"列直接编辑 |
| 排除整段 | 右键片段 → "排除此片段"（被排除的不导出，可再右键恢复） |
| 只看某个人 | 点左侧说话人；再点一次回到全部 |
| 给人改名 | 右键左侧说话人 → "重命名" |
| 把两个人的片段并成一个 | 按住 Ctrl 点选多个说话人 → 右键 → "合并 N 个人物" |

## 七、导出结果

默认导出到素材旁边的"导出"文件夹，结构是：

```
导出/
├── 说话人01/
│   └── 说话人01.wav     ← 这个人的所有保留片段，按时间顺序拼接
├── 说话人02/
│   └── 说话人02.wav
├── 未分配/
│   └── 未分配.wav
└── 片段清单.csv         ← 每段的起止时间、人物、文字
```

人物文件夹名跟界面里的名字一致，改名后导出就是新名字。
被排除的片段不会进入 WAV，但仍会出现在 CSV 里（状态列可对照）。

## 八、中间文件在哪

处理过程中会在素材旁边生成 `<文件名>_output/`：

- `_work/` —— 提取的音轨、去背景音乐后的人声、16k 分析音频
- `project.json` —— 本次分析结果，方便以后排查

导出可以在别处，这些中间文件不会自动删除。

## 九、命令行（可选）

批量处理时可以直接跑命令行：

```bash
.\run.bat "素材.mp4"
.\run.bat "素材.mp4" -o D:\输出 --no-clean
.\run.bat "素材.mp4" --list-tracks
```

常用参数：

- `-o` 输出目录（默认 `<文件名>_output`）
- `-t` 音轨序号（默认 0）
- `--no-clean` 跳过去背景音乐
- `--model` 换 whisper 模型（默认 large-v3-turbo）
- `--language zh` 指定语言（默认自动识别）
- `--device cpu` 强制用 CPU
- `--threshold 0.5` 声纹聚类阈值，数值越大越容易分成更多人
- `--speakers 3` 已知人数时直接指定

## 十、常见问题

**处理很慢？**
人声分离最耗时。短素材追求干净就用默认模型；
长素材可以在 设置 › 人声分离 里换成 Demucs（30 秒音频约 1 秒），或直接把处理方式选成「保留原声」。

**同一个人被分成了好几个人？**
程序会自动做一次声纹合并（把长片段声纹相近的说话人并到一起），并把"总共说话不到 3 秒"的簇并入未分配。
仍不对时，在左侧按住 Ctrl 点选那几个人 → 右键 → "合并 N 个人物"，一次就并好；
命令行可用 `--merge-sim` 调合并松紧（默认 0.8，越大越保守）。

**模型下载失败？**
关掉程序重开，会自动续传。GitHub 相关下载可设置环境变量
`GITHUB_PROXY=https://gh-proxy.com/`。

**没有显卡能用吗？**
能。所有步骤都有 CPU 路径，只是慢一些。

**支持哪些格式？**
MP4 / MOV / MKV / AVI / FLV / WEBM / WAV / MP3 / M4A / AAC / FLAC / OGG。
