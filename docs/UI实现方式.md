# SpeakerSplit 界面实现方式

> 只讲界面是怎么做出来的，不涉及业务功能。

## 一、总体技术路线

- 技术栈：**PySide6 / Qt 6 Widgets**，原生控件 + 自绘，没有使用 WebView、HTML 或 QML。
- 分三层实现：
  1. **QSS**：静态外观、字体、间距、配色选择器；
  2. **QPainter 自绘**：手工绘制需要渐变、阴影、波形、指针跟随等 QSS 表达不了的细节；
  3. **Qt 动画 + 自绘**：所有过渡效果都由动画器改数值、驱动重绘实现。
- 相关文件分工：

| 文件 | 职责 |
|---|---|
| `ui/main_window.py` | 主窗口组装、视图切换、背景绘制、播放条 |
| `ui/widgets.py` | 全部自绘组件、动画组件、表格与时间轴 |
| `ui/theme.py` | 浅色/深色色板、QSS 生成、颜色访问器 |
| `ui/editor.py` | 内嵌编辑视图：工具栏、轨道画布、缩放与拖拽 |
| `ui/menus.py` / `ui/dialogs.py` | 玻璃菜单、提示气泡、对话框 |
| `ui/settings_dialog.py` | 设置页 |

## 二、窗口层

### 2.1 无边框窗口

- `Qt.FramelessWindowHint` 去掉系统边框，窗口自己绘制圆角背景与描边。
- `paintEvent` 中先用 `QPainterPath.addRoundedRect` 建立圆角裁剪区域，再画背景，最后补一圈半透明描边。
- 运行时调用 DWM 接口（`DwmSetWindowAttribute`，属性 33）让 Windows 11 给窗口套系统圆角，和自绘圆角叠加使用。

### 2.2 背景

- 背景由一层底色 + 若干径向渐变光斑组成，光斑位置按正弦函数缓慢漂移（10fps 定时器触发重绘），形成"液态玻璃"的环境光。
- `paint_background_into()` 可将同一背景单独画到别的绘制器上，供需要不透明背景的子控件（如表格）做快照使用。

### 2.3 阴影

- 卡片的投影不是实时模糊，而是 `make_shadow()` 预渲染成带透明通道的 `QPixmap`（按尺寸与圆角缓存），窗口重绘时直接贴图，避免每帧做模糊运算。

## 三、主题系统

### 3.1 色板与 QSS

- `theme.py` 中维护 `LIGHT` / `DARK` 两套色板（背景、文本、描边、卡片渐变、悬浮、选区等）。
- `theme.qss()` 用当前色板拼出整份样式表，交给 `QApplication.setStyleSheet()` 全局下发。
- 控件通过 `objectName` 命中样式，例如 `#Card`、`#SideTitle`、`#PlayerMeta`、`#Hint`。切换主题只需重新生成并应用样式表，普通控件自动变色。

### 3.2 自绘控件取色

- 自绘控件无法用 QSS，通过 `theme.c("text")` 取 `QColor`、`theme.s("text2")` 取颜色字符串。
- 约定：**主题色不写死在控件里**，否则切深色会出现不可读的文字（本项目踩过这个坑，播放条时间标签、阶段标签都改成了 objectName 方案）。

### 3.3 圆形扩散过渡

- `ThemeTransition` 覆盖层：
  1. `win.grab()` 截下旧界面；
  2. 应用新主题；
  3. 用 `QVariantAnimation` 从 0 到 1 推进，绘制时用 `full.subtracted(hole)` 裁掉一个半径递增的圆，露出新界面。
- 圆心取鼠标点击位置，半径取到窗口四角的最大距离。

## 四、布局结构

### 4.1 主窗口

```
MainWindow（无边框，自绘背景）
├─ TitleBar（自绘，52px）
│  ├─ left_lay   齿轮、Logo、品牌名、状态胶囊
│  ├─ center_box 视图分段开关（手动居中）
│  └─ right_lay  文件胶囊、换文件、主题、主按钮、窗口按钮
├─ 内容区（左右两栏）
│  ├─ 左栏卡片：导入按钮、步骤栏、说话人/素材库
│  └─ 右栏 QStackedWidget
│     ├─ 检查页：时间轴卡片 + 片段表格卡片
│     └─ 编辑页：编辑视图（工具栏 + 画布 + 试听条 + 状态栏）
└─ 播放条（三段式）
```

- 卡片统一由 `make_card()` 生成玻璃 QFrame，内容用 QVBox/QHBox 排列。

### 4.2 标题栏居中技巧

- 左右两组内容宽度会随文件胶囊变化，放在 `QGridLayout` 里中列并不绝对居中。
- 做法：左右两组进网格，中间分段开关不进网格，作为子控件在 `resizeEvent` 里按 `(宽 - 控件宽) / 2` 手动定位并 `raise_()`。

### 4.3 表格

- `SegmentTable` 继承 `QAbstractScrollArea`，使用 `setViewportMargins(0, HEADER_H, 0, 0)` 给固定表头留位置。
- 表头 `TableHeader` 是独立子控件，`WA_TransparentForMouseEvents`，滚动时只更新它的"是否已滚动"状态，用于切换底部阴影。
- 列宽按窗口宽度动态计算：固定列 + 弹性文本列。

### 4.4 编辑画布与缩放

- 画布放在 `QScrollArea` 中，`widgetResizable=True`。
- 缩放不改变坐标公式，而是设置画布**最小宽度** = 头部宽 + 时长 × 每秒像素数 + 余量；滚动区自动出现横向滚动条，画面按当前宽度等比映射时间。
- 缩放滑杆用对数映射（6–160 px/s），拖动时只改最小宽度并重绘。

## 五、自绘控件与实现技巧

### 5.1 文字位图缓存

- 表格中文字会被指针附近放大，如果每帧重新排版会卡顿。
- `_TextCache` 按最大放大倍数把文字**预渲染成 QPixmap**（键包含文字、字体 key、颜色、设备像素比），绘制时只缩放位图。
- 超过上限（3000 条）整体清空重来，避免无限增长。

### 5.2 表格的指针跟随与放大

- 高亮条位置使用**内容坐标**（滚动前后只换算一次），而不是视口坐标，解决白条跳动问题。
- 每行维护弹簧状态（位置、速度），由全局统一的 16ms `Ticker` 做数值积分，指针靠近时放大、离开后回落，形成 Dock 效果。
- 整个表格只重绘视口，并在 `paintEvent` 里按行判断是否落在脏矩形内，跳过不可见行。

### 5.3 时间轴与波形

- 直接绘制：彩色圆角条表示说话人片段，下方按峰值数组绘制对称波形柱；已播放部分换色。
- 点击换算成时间，双击或"显示全部"重置视图范围。

### 5.4 常见控件清单

| 控件 | 实现要点 |
|---|---|
| `ViewSwitch` | 自绘分段控件，白色滑块用动画平移 |
| `FileChip` | 圆点 + 省略号文件名 + 等宽时长，宽度随内容收缩并设上限 |
| `ImportButton` | 线性渐变圆角、箭头图标、悬停/按下缩放 |
| `StepRail` | 每步圆形序号/对勾 + 名称 + 耗时，当前步蓝底，连接线按完成状态变色 |
| `PersonRow` | 圆形头像（取序号）+ 名称 + 句数/时长，选中态整行底色 |
| `PlayButton` | 播放/暂停图标交叉淡入旋转，点击触发果冻缩放 |
| `MorphSlider` | 轨道高度与滑块形状随拖拽变化 |
| `ShineProgress` | 进度条内循环流光（用裁剪 + 位移动画实现） |
| `DropZone` | 虚线框 + 悬浮图标 + 格式标签 |

## 六、动效系统

- Qt Widgets 没有 CSS transition / animation，统一模式是：
  **`QVariantAnimation` / `QPropertyAnimation` 改数值 → `update()` → `paintEvent` 按新数值重绘**。
- 需要逐帧积分的动画（表格放大、进度条流光）共用全局唯一的 `Ticker`：16ms 精确定时器，注册回调返回 `False` 即自动注销；最后一个回调退出时定时器停止，并广播 `activeChanged` 让背景环境光暂停/恢复。
- 缓动曲线用 `QEasingCurve` 近似设计稿的弹簧手感；按钮按下/松开分两段时长（按下快、回弹慢）。
- 播放键"果冻"是分段的 scale 关键帧动画；表格放大是用定时器做弹簧-阻尼积分，接近真实物理。
- 所有动画都只触发局部 `update()`，避免整窗重绘。

## 七、交互输入

- 画布内所有点击都先做**坐标换算**（像素 ↔ 时间），再判断命中区域（标尺、轨道头、片段、空白）。
- 片段拖动、两端裁剪、跨轨道移动共用同一套按下/移动/松开状态机，拖动中实时改模型并重绘，松手时提交一次撤销。
- 拖拽数据统一用 `QDrag` + 自定义 MIME 类型（`application/x-speakersplit-segment`），源方（表格、素材库）负责打包 JSON，目标方（画布）在 `dropEvent` 解析并按落点创建对象。
- 键盘：空格播放、Ctrl+Z / Ctrl+Shift+Z、Ctrl+D、Delete / Shift+Delete、S 等快捷键在窗口层统一分派。
- 撤销使用 `QUndoStack`，命令里保存操作前后的工程快照，撤销/重做只做对象替换加刷新。

## 八、性能与线程边界

- 界面线程只做绘制与轻量计算；文件探测、波形提取、音频峰值、混音渲染、识别流水线全部在 `QThread` 中执行，通过信号回到界面。
- 工作线程栈显式设为 64MB，避免长音频推理时爆默认 1MB 栈。
- 波形峰值用 `soundfile` 分块流式读取，避免整段载入内存。
- 表格、时间轴在 `paintEvent` 里记录耗时并周期性打印日志（`[table] paint avg=...`），方便观察性能回归。

---

## 九、约定与注意事项

1. 主题相关颜色一律走 `theme.c()` / `theme.s()` 或 QSS，禁止在控件构造时硬编码当前主题色。
2. 自绘控件在 `paintEvent` 中只读状态，状态修改放在事件处理或动画回调里。
3. 会随窗口尺寸变化的自绘元素（标题栏居中块、画布宽度）放在 `resizeEvent` 里重算。
4. 文字缓存、阴影缓存、峰值缓存都要设上限或键控清理，防止长期运行内存增长。
