# SpeakerSplit UI 布局说明

> 版本：液态玻璃版（v0.2 界面）
> 风格：浅色 + 半透明玻璃卡片 + 彩色环境光，单一蓝色强调

---

## 1. 设计原则

| 原则 | 落地方式 |
|---|---|
| 一屏完成 | 导入、处理、检查、导出都在同一窗口，左侧竖排步骤指示进度 |
| 一个主行动 | 右上角只有一个主按钮，随状态切换：选择文件 → 开始处理 → 导出 |
| 玻璃层次 | 窗口底是柔和的彩色环境光，内容用半透明白卡片浮在上面 |
| 克制的动效 | 按钮悬停放大、按下回弹；播放键弹性缩放；其余保持安静 |
| 信息分层 | 主文字 #1D1D1F，次级 rgba(60,60,67,.62)，弱化 rgba(60,60,67,.34) |

> 说明：Windows 上 Qt 无法对每个面板做背景模糊，卡片用半透明白 + 细白边模拟玻璃质感；窗口整体的圆角与环境光是自绘的。

---

## 2. 窗口结构

无边框窗口，默认 1240 × 840，圆角 20，可拖动、双击标题栏最大化、右下角可缩放。

```
┌──────────────────────────────────────────────────────────────┐
│ ● ● ●                                          ① 标题栏 34px │
├──────────────────────────────────────────────────────────────┤
│ SpeakerSplit [状态]                     [工具胶囊组] [换文件][主按钮] │
│ 副标题                                                        │
│ ─────────────────────────────────────────────────────────────│
│ 阶段文字 [────────进度────────] 42%            ② 进度区        │
├──────────┬───────────────┬───────────────────────────────────┤
│ ④ 步骤栏  │ ⑤ 说话人卡片   │ ⑥ 时间轴卡片                       │
│  (104px) │   (212px)     ├───────────────────────────────────┤
│          │               │ ⑦ 片段表格卡片                     │
├──────────┴───────────────┴───────────────────────────────────┤
│ ⑧ 底部播放条                                                  │
└──────────────────────────────────────────────────────────────┘
```

空状态时：步骤栏、人物卡片、时间轴、表格、播放条全部隐藏，中间是一整块拖放区。

## 3. 分区说明

### ① 标题栏（34px）

左上角三个圆点：红（关闭）、黄（最小化）、绿（最大化）；其余区域可拖动窗口，双击切换最大化。

### ② 顶部工具栏

```
SpeakerSplit [待检查]                                  ┌ 工具胶囊组 ─────────────┐  [换文件] [导出]
把视频或音频拖到这里…                                  │ 去人声 ⌄ │ 切换模型 ! │ 识别: 标准 ⌄ │
```

- 标题 22px / 700
- 状态胶囊：`已导入`（蓝）、`处理中`（橙）、`待检查`（绿）、`已导出`（灰）
- 副标题：空闲为引导语；载入后为 `文件名 · 时长 · 类型 · 音轨数`；完成后追加 `· N 位说话人 · 耗时`
- 工具胶囊组：一个 38px 高的玻璃胶囊，内含音轨下拉（多轨时出现）、去人声下拉、切换模型按钮、橙色 ❗、识别模型下拉，中间用 1px 竖线分隔
- ❗：悬停弹出全部模型参数气泡
- 换文件：次要按钮，仅有素材时出现
- 主按钮：蓝色渐变胶囊，按状态变化；无素材时不显示（空状态中间已有入口）

### ③ 进度区

处理时才出现的一行：阶段文字（84px）、细进度条（6px，蓝色渐变）、百分比。

### ④ 步骤栏（104px）

竖排五项：导入 / 清理 / 分析 / 检查 / 导出。

- 当前步骤：蓝色圆形数字 + 浅蓝胶囊底 + 蓝色文字
- 已完成：黑色圆形打勾，连接线为深色
- 未开始：白色空心圆 + 灰色数字，连接线浅灰

### ⑤ 说话人卡片（212px）

标题"说话人"，每行：色点（11px）+ 名称 + 片段数。

- 悬停：白色半透明底；选中：浅蓝底
- 单击筛选，再点恢复全部
- Ctrl 多选 + 右键合并；右键重命名
- 处理中显示"正在识别说话人…"，完成后显示人物列表

### ⑥ 时间轴卡片

标题行：`时间轴　点击跳转` …… 右侧 `[显示全部]`（放大时出现）+ 总时长。

时间轴区域（118px，圆角 14，半透明白底）：

```
[说话人彩色胶囊条 18px，带顶部高光]
[真实音频波形：未播放中灰、已播放蓝色]
[刻度与时间]
[播放头：蓝色竖线 + 白底蓝芯圆点]
```

- 单击跳转并自由播放；双击或"显示全部"恢复全景
- 单击表格某行：视图缩放到该句前后

### ⑦ 片段表格卡片

标题行：`片段  8`，筛选时右侧出现"显示全部"。

| 列 | 宽度 | 内容 |
|---|---|---|
| 开始 | 72 | `mm:ss` |
| 结束 | 72 | `mm:ss` |
| 人物 | 96 | 人物颜色 + 加粗 |
| 文字 | 自适应 | 双击编辑 |
| 状态 | 72 | `重叠`（橙）/ `已排除`（灰） |

行高 38，行间 1px 极浅分隔线，悬停整行泛白，选中行浅蓝。

### ⑧ 底部播放条（68px）

```
[封面方块 44]  未在播放        ⥀5  ▶  ⥁5   0:00  [────●────]  -0:56   🔊 [───]
                SpeakerSplit · 本地处理
```

- 左侧封面方块会显示当前说话人的颜色，标题显示 `● 说话人01`，副标题显示该句文字
- 中间：后退 5 秒、播放/暂停（46px 玻璃圆键）、前进 5 秒
- 右侧：当前时间、进度滑块、剩余时间、静音按钮 + 音量滑块
- 空格键播放/暂停（编辑文字时不触发）

### 空状态拖放区

占满主体区域的圆角玻璃面板，内部有一圈虚线框：

- 76px 白色圆角图标（蓝色波形）
- "把视频或音频拖到这里"（19px / 600）
- 两行说明：支持格式 + 全程本地处理
- 蓝色"选择文件"按钮
- 拖入文件时：面板底色变淡蓝、边框变蓝

## 4. 对话框

统一为半透明白玻璃卡片、24 圆角、带投影，居中出现。

### 4.1 模型列表

宽 640。每行两行文字 + 右侧状态：

```
● MelBand RoFormer（Kim）                                 已下载
  效果 12.60 · 871 MB · 30 秒音频约 5 秒 · 2.0 GB 显存
```

- 当前模型行浅蓝底；`已下载` 蓝色、`未下载` 灰色
- 底部 `取消` / `使用此模型`
- 选中未下载 → 确认框 → 对话框内显示下载进度条 → 完成自动切换

### 4.2 通用提示 / 输入框

- 标题 15px / 600，正文次级灰
- 右下角按钮：次要玻璃、主行动蓝色
- 输入框白底圆角，聚焦时蓝色描边

## 5. 视觉规范

| 项目 | 取值 |
|---|---|
| 窗口底色 | rgba(242,242,247,0.82) + 四角环境光（蓝 / 紫 / 粉 / 青） |
| 卡片 | 白 64% → 44% 竖向渐变，1px 白色边框，圆角 18 |
| 工具胶囊组 | 白 74% → 51%，圆角 19 |
| 主文字 / 次级 / 弱化 | #1D1D1F / rgba(60,60,67,.62) / rgba(60,60,67,.34) |
| 强调色 | #007AFF（悬停 #1A88FF，按压 #0062CC） |
| 选中底 | rgba(0,122,255,.12) |
| 分隔线 | rgba(60,60,67,.12) |
| 说话人色 | #007AFF / #34C759 / #FF9500 / #AF52DE / #FF3B30 / #5AC8FA / #FFCC00 / #5856D6 |
| 字体 | Segoe UI Variable Text → 微软雅黑；正文 13px |
| 圆角 | 窗口 20、卡片 18、按钮 15、输入 10 |

## 6. 状态与空状态

| 状态 | 界面表现 |
|---|---|
| 无素材 | 只显示标题栏、标题、拖放区；工具栏控件与播放条隐藏 |
| 已导入 | 工具栏与播放条出现；时间轴空；表格区显示"素材已就绪"；人物卡片显示"处理完成后..." |
| 处理中 | 进度条出现，主按钮变"处理中…"并禁用；步骤停在"分析"；表格区显示"正在处理… 阶段名" |
| 处理完成 | 人物列表、波形、片段表填充；主按钮变"导出"；状态胶囊"待检查" |
| 已导出 | 胶囊变"已导出"（灰） |

## 7. 交互清单

| 操作 | 结果 |
|---|---|
| 拖入文件 / 选择文件 | 读取元信息，进入"已导入" |
| 单击表格行 | 波形放大到该句 + 只播这一句，播完自动停 |
| 双击文字列 | 编辑文字 |
| 右键片段 | 试听 / 排除 / 恢复 |
| 单击左侧人物 | 只看该人；再点恢复 |
| Ctrl 多选人物 + 右键 | 合并 |
| 右键人物 | 重命名 |
| 单击时间轴 | 跳转并自由播放 |
| 双击时间轴 / 显示全部 | 恢复全景 |
| 空格 | 播放 / 暂停 |
| 标题栏拖动 / 双击 | 移动窗口 / 最大化切换 |
| 关闭窗口（处理中） | 确认后终止处理 |

---

## 8. 已知限制

- 没有做真正的背景模糊（Qt 在 Windows 上不支持逐面板模糊），用半透明白近似
- 设计稿里的表格行"悬浮放大镜"效果未实现，改为整行悬停高亮
- 多人重叠只标记不拆分；自动合并可能偏保守或偏激进，可用手动合并兜底
