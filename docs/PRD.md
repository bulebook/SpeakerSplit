---

## 1. 背景与问题

处理访谈、会议、游戏录屏、直播回放这类素材时，常见需求是**把不同人说的话分开，按人导出音频**，用于剪辑、配音替换、素材归档。现有做法要么依赖云端服务（素材需上传，隐私不可控），要么需要手工反复听、反复切。

本产品解决的是：**在一个本地应用里，把"导入 → 去背景音 → 识别说话人 → 转写 → 人工校对 → 按人导出"串成一条完整流水线，全程不上传素材。**

---

## 2. 目标与非目标

### 2.1 目标

1. 一段 1 小时左右的多人素材，能在 10~20 分钟内自动分出人物并产出可用的按人音频
2. 自动结果允许人工修正（改名、合并、排除、改文字），修正后直接反映到导出
3. 全程本地运行，断网可用（模型下载完成后）
4. 有 N 卡用 N 卡，没有也能跑

### 2.2 非目标（v0.1 不做）

1. 不做实时转写 / 直播字幕
2. 不做云端同步与多人协作
3. 不做视频剪辑（不导出视频，只导出音频）
4. 不承诺把"两人同时说话"的重叠语音真正拆开（只做标记提示）

---

## 3. 目标用户与场景

| 用户 | 场景 | 关注点 |
|---|---|---|
| 视频剪辑 / 自媒体 | 访谈、播客多人对话按人拆音轨 | 干净、快、能校对 |
| 会议记录 | 多人会议录音整理成按人音频与文字 | 人数识别准、导出结构清晰 |
| 素材归档 | 游戏录屏、直播回放的语音归档 | 批量、可离线、隐私 |

典型素材特征：单文件 10 分钟 ~ 2 小时；方言口音重；背景有音乐、音效；存在抢话重叠。

---

## 4. 术语

| 术语 | 含义 |
|---|---|
| 片段 / utterance | 一个人连续说的一小段话，含起止时间、文字、说话人 |
| 说话人簇 / 簇 | 声纹聚类得到的一组片段 |
| 人声分离 | 从混音中去掉背景音乐与环境音，保留人声 |
| 声纹合并 | 把声纹相似的两个簇判定为同一人 |
| 重叠 | 两个不同说话人的语音区间在时间上交叠 |

---

## 5. 用户旅程

```
拖入素材
  → 选择是否去人声、选择分离模型
  → 开始处理（分离 → 转写 → 说话人识别 → 自动合并）
  → 查看结果：人物列表 / 波形时间轴 / 片段表
  → 单击片段试听，判断归属是否正确
  → 改名 / 多选合并 / 排除错误片段 / 修正文字
  → 导出：每人一个 WAV + 一份片段清单 CSV
```

## 6. 功能需求

### 6.1 导入（P0 ✅）

| FR-02 | 自动判断类型并提取音轨 | 视频提取音轨，音频直接使用 |
| FR-03 | 多音轨视频可选音轨 | 顶部出现音轨下拉，默认第一条 |
| FR-04 | 拖放与文件对话框两种方式 | 拖入窗口任意位置均可 |

### 6.2 人声分离（P0 ✅）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-06 | 可开关：去人声 / 保留原声 | 默认开启 |
| FR-07 | 提供多个分离模型可选 | 当前 7 个：MelBand RoFormer、BS-RoFormer、MDX23C、UVR-MDX-NET Main406、Kim Vocal 2、UVR-MDX-NET Voc FT、Demucs |

## 8. 输出规格

### 8.1 目录结构

```
素材名_output/            ← 处理中间产物与项目文件
├── _work/
│   ├── original.wav      ← 提取出的原始音轨
│   ├── analysis16k.wav   ← 16k 单声道分析音频
│   └── demucs/…          ← 分离后的人声
└── project.json          ← 片段、人物、语言、耗时等

导出/
├── 说话人01/说话人01.wav
├── 说话人02/说话人02.wav
├── 未分配/未分配.wav
└── 片段清单.csv
```

### 8.2 CSV 字段

`人物, 序号, 开始(秒), 结束(秒), 时长(秒), 开始时间, 结束时间, 文字, 备注`

- 时间格式 `HH:MM:SS.mmm`
- 备注：`疑似重叠` 或空
- 编码 UTF-8 with BOM（Excel 直接打开不乱码）

## 9. 技术方案（概要）

| 环节 | 方案 |
|---|---|
| 媒体探测 / 提取 | ffmpeg / ffprobe |
| 人声分离 | UVR 系模型（audio-separator + torch），兼容 Demucs |
| 转写 | faster-whisper（CTranslate2），词级时间戳 |
| 说话人分割 | sherpa-onnx：pyannote segmentation 3.0 |
| 声纹嵌入 | 3D-Speaker CAM++（中文） |
| 聚类 | sherpa FastClustering + 自研质心二次合并（scipy 层次聚类） |
| 对齐 | 词级时间戳与说话人区间按重叠最大归属，再按停顿合并成句 |
| 导出 | soundfile 流式切分拼接 |
| 界面 | PySide6 + 自绘时间轴；QMediaPlayer 播放 |
| 打包 | PyInstaller onedir |

### 9.1 分离模型对比（本机实测，30 秒素材）

| 模型 | 文件 | 显存 | 内存 | 耗时 | SDR |
|---|---|---|---|---|---|
| MelBand RoFormer (Kim) | 871 MB | 1.97 GB | 1.2 GB | 4.7 s | 12.60 |
| BS-RoFormer 317 | 610 MB | 1.58 GB | 1.0 GB | 21.1 s | 11.77 |
| MDX23C-InstVoc HQ | 428 MB | 1.57 GB | 1.4 GB | 15.5 s | 10.56 |
| UVR-MDX-NET Main406 | 64 MB | CPU | 3.0 GB | 19.5 s | 10.44 |
| Kim Vocal 2 | 64 MB | CPU | 3.0 GB | 18.9 s | 10.18 |
| UVR-MDX-NET Voc FT | 64 MB | CPU | 3.0 GB | 19.0 s | 10.15 |
| Demucs htdemucs | 81 MB | 0.54 GB | 0.9 GB | 1.3 s | ≈8.9 |

## 10. 验收标准

1. 拖入一段 60 分钟、含多人对话的 mp4，默认设置下 30 分钟内完成，界面全程可响应
2. 结果中出现合理数量的说话人（10 人以上素材不得崩溃），且能人工合并成正确人数
3. 任意片段单击后只播放该句并在句尾停止；空格键可暂停/继续
4. 排除某段后重新导出，该段不出现在任何 WAV 中，CSV 中仍有记录
5. 导出目录结构与人物名一致，改名后导出目录同步改
6. 断网状态下（模型齐全）可完整处理
7. 无 NVIDIA 显卡的机器可完成全流程（速度慢）
8. 打包版在无 Python 环境的 Windows 上可双击运行（系统需有 ffmpeg）

## 11. 风险与限制

| 风险 | 影响 | 应对 |
|---|---|---|
| 重叠语音无法真正拆分 | 抢话片段归属只给一个人 | 标记提示 + 人工排除；后续可接入语音分离模型 |
| 长音频聚类不稳定 | 人数偏多或少 | 二次合并 + 人工合并；后续可分块聚类 |
| 方言识别不准 | 文字错漏 | 提供 large-v3 高精度档；后续可接方言专用 ASR |
| 分离模型体积大 | 分发体积大 | 本机只保留默认模型，其余按需下载 |
| 依赖系统 ffmpeg | 换机可能报"无法读取文件" | 分发时需一并打包 ffmpeg（待办） |
| 显存 6 GB 以下机器 | 大模型可能 OOM | 提供小模型（64 MB ONNX 系列） |

## 12. 路线图

### v0.1（当前）

导入、人声分离（多模型管理）、转写、说话人识别与合并、重叠标记、校对（改名/合并/排除/改字/试听）、按人导出、GPU 加速、打包分发。

### v0.2（候选，按价值排序）

1. 片段切分 / 边界调整 / 跨人物移动
2. 撤销重做
3. 自动保存与崩溃恢复
4. 批量文件夹处理
5. 打包内置 ffmpeg，摆脱系统依赖
6. 字幕 / 文字稿导出（SRT / TXT）

### v0.3（探索）

1. 重叠语音分离（SepFormer 类）
2. 方言专用识别模型
3. 分块聚类以提升长音频准确率
4. macOS / Linux 版本
